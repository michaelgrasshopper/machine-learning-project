# machine-learning-project

**Project description:**
This project set out to predict wine quality directly from a wine's chemical fingerprint rather than relying solely on human sensory panels. We used the UCI Wine Quality dataset (Cortez et al., 2009), combining separate red (1,599 samples) and white (4,898 samples) Vinho Verde wine files into a single dataset of 6,497 records, each described by 11 physicochemical measurements — fixed and volatile acidity, citric acid, residual sugar, chlorides, free and total sulfur dioxide, density, pH, sulphates, and alcohol — plus an engineered wine_type flag distinguishing red from white; after removing 1,177 exact duplicates, 5,320 unique wines remained, with the original 0–10 quality score re-binned into three classes (Low, Medium, High) that turned out to be heavily imbalanced, with Low-quality wines making up just 4.4% of the data. To tackle this, we progressively built and compared five models of increasing sophistication: a Basic Random Forest baseline with no imbalance handling, a Weighted Random Forest that penalized errors on rare classes, an XGBoost classifier combined with SMOTE oversampling and tuned via Randomized and Grid Search, a Cost-sensitive XGBoost model using sample weighting instead of synthetic data, and an XGBoost Regression model that predicted the raw 3–9 quality score directly — evaluating all of them with accuracy, macro F1, and per-class recall under an 80/20 stratified train/test split with 3-fold cross-validation. The key finding was that accuracy alone was deeply misleading: the Random Forest models achieved the highest accuracy (~80%) but the lowest macro F1 (~0.46) because they almost never predicted the rare Low or High classes, whereas the Cost-sensitive XGBoost model, despite the lowest accuracy (65%), achieved the best macro F1 (0.546) and far stronger recall on the extremes (64% for Low, 78% for High) — with alcohol, free sulfur dioxide, volatile acidity, density, and wine type emerging as the most predictive features, underscoring that in imbalanced, quality-critical problems like this one, balanced performance metrics matter more than raw accuracy when choosing a production model.
